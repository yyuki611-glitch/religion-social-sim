### 創発的知見（v0.5.0 で新たに出たもの）

1. **規模の増幅効果**: famine の per-capita 改宗率が 22.5% → 37.8% に増えた。村が大きく
   多様になると、最初の改宗者が共同体圧力チャネルを通じて後続の改宗を呼ぶ（8人村では
   この連鎖が起きる前に候補が尽きる）
2. **対処チャネルの競合**: practical_benefit_need を上げると実利系改宗が増える一方で
   **救済系改宗が減る**（famine: salv 12.83→5.73）。救済と実利は危機対処の競合チャネル
3. **寛容性の流動化はなめらかに再現**: 8人村では閾値跨ぎが 0/8→8/8 の離散ジャンプ

   v0.4.0 の「寛容＝流動化」がアーティファクトでないことを補強
4. **噂改宗の蒸発は村構成に対して頑健**: どの村でも噂経由の早期改宗者の約8割が離脱する

## 2026-06-06（v0.6.0 graded 習合メカニズム、スイープ E、H6 初判定）

設計（tasks/todo.md rev3、evaluator モード1 APPROVE）に基づく。H6 はこれまで
「tolerance >= 0.65 の二値ゲートが習合を直接決めるトートロジー」で検証不能だった。
v0.6.0 で改宗時の保持/放棄を競合スコア（寛容 0.50 / 旧信仰強度 0.30 / 伝統 0.20 vs
gap 正規化 + 新奇 0.35）で決める graded メカニズムを導入し、初めて判定した。

- 再現: `experiments/run_sweep.py --sweep tolerance_graded --judge`（sampled60 + graded、300 run）
- 重みは実装後・スイープ E 実行前に凍結（コミット 1bc8ece）。較正は threshold 実験の
  改宗時 gap 分布（中央値 0.18 / p90 0.29、450件）のみを使用
- 決定性: 2回実行 byte 一致。後方互換: fixed8 が v0.4.0 タグと、sampled60 A–D が
  v0.5.0 タグと、新コードで再生成しても全ファイル byte 一致（メカニズムはフラグ分離）

### H6 判定: **整合**（宣言基準 (a)(b)(c) 全成立）

| tolerance デルタ | -0.20 | -0.10 | 0 | +0.10 | +0.20 |
|---|---|---|---|---|---|
| famine 習合 | 4.07 | 4.43 | 5.43 | 5.87 | 6.27 |
| famine 完全改宗 | 24.40 | 24.60 | 25.50 | 25.83 | 26.20 |
| famine 習合シェア | 0.141 | 0.151 | 0.172 | 0.182 | 0.189 |

- (a) 習合数 単調増加（減少0箇所）✓ / (b) 習合シェア 単調増加 ✓ / (c) 最大 6.27 ≥ 下限3 ✓
- **置き換えか共増加か（宣言済みの区別）**: **共増加型**。完全改宗も微増（24.4→26.2）して
  おり、習合が改宗を奪ったのではなく「寛容な村では信仰変化の総量が増え、その中で習合の
  比重が高まる」。「習合が改宗を置き換える」という強い読みの H6 ではなく、
  「寛容性は信仰変化を習合側へ傾ける」という弱い読みでの整合である
- 注意: tolerance は graded ミクロルールに重み 0.50 の一要因として入っており、
  ここで言う整合は「マクロな置換パターンが観察された」こと。ミクロに入っている事実
  そのものは判定根拠にしていない（設計 rev3）

### 創発的知見（v0.6.0）

1. **危機は習合を許さない**: 平時（baseline）の信仰変化は約3割が習合（シェア 0.285–0.316）
   なのに、危機下（famine）では 0.141–0.189 に下がる。強い引力（gap）は keep/drop 綱引きで
   drop を勝たせるため、危機は「古い神を抱えたままの緩やかな変化」を許さず完全改宗を強いる
2. **最終的に副次信仰を持つ村人は寛容度に比例**（baseline: 0.4 → 1.93人）。
   ただし graded では threshold より副次保持が厳選される（保持は綱引きに勝った場合のみ）

### アブレーション（2026-06-06 追補。独立批判レビューの処方箋3に対応）

「習合シェアの単調増加は tolerance がミクロルールに入っていることの素通りでは」という
批判に答えるため、tolerance の寄与を**両チャネルからゼロ化**（W_KEEP_TOLERANCE=0、
W_SYNC_OPEN_TOLERANCE=0）した対照実験を実施（famine × 5デルタ × 30 seeds、/tmp 出力・
非コミット。判定済みスイープEの重みは変更していない）:

| | sync | share |
|---|---|---|
| アブレーション（tolerance寄与ゼロ） | 全デルタで 2.20 固定 | 全デルタで 0.086 固定 |
| 本実験 | 4.07 → 6.27 | 0.141 → 0.189 |

- 解釈: (1) tolerance がなくても習合は起きる（novelty・anxiety チャネルで share 8.6%）、
  (2) 本実験のデルタ応答は tolerance チャネルに完全に帰属し、習合を約2〜3倍に押し上げる、
  (3) 批判レビュー自身の基準「tolerance なしでは習合が有意に減るならば『弱い読みでの整合』に
  実質的な根拠が生まれる」を満たす
- 限界も明記する: アブレーションのフラットさは「graded で tolerance が他の経路を持たない」
  ことの帰結でもあり、これは創発の証明ではなく**寄与の定量分離**である

### 独立批判レビューの記録（2026-06-06）

プロジェクト全体に対する破壊的レビュー（落とす前提の学術査読スタイル）を実施した。
主要な指摘と対応:

1. **H1/H2 の方向性は配線由来**（events.tsv の target_belief と APPEAL_TRAITS が結論方向に
   配線されている）→ 認める。README に「主張できること/できないこと」を明記。判定基準が
   測っていたのは構成比・規模・単調性などの定量面であり、方向性そのものは設計の確認
2. **「入口で定着が違う」「噂は蒸発」も部分的にシナリオ設計の産物** → 認める。シナリオの
   イベント列（庇護・スキャンダル）が揺り戻しに寄与しており、純粋な噂減衰との分離は未実施
3. **パラメータ出典の循環**（population.yaml ← agents.tsv ← 出典なし）→ 認める。全特性値は
   歴史史料に基づかない設計上の仮定であることを明記。感度分析は次フェーズ
4. **学術文献ゼロ・統計的検定なし・AI身内レビュー** → 認める。README に開示
5. **pstdev の使用は分散過小評価方向** → 認める。n=30–50 では stdev との差は ~2% 未満で
   判定（H1 のマージンは 22.7 vs 5.68）を覆さないが、次フェーズで不偏分散へ移行予定
6. **H6 アブレーション未実施** → 上記の通り実施済み（結果は弱い読みの整合を補強）

総合判定は「学術研究としては REJECT / GitHub の趣味研究としては PASS」。本リポジトリの
位置づけは「学術研究」ではなく**「再現性と誠実な報告を重視した宗教伝播 ABM の実装実験」**である。
