## 2026-06-05（v0.2.0 初回実行、seed=42）

| シナリオ | 改宗 | 習合 | 定着率 | 観察 |
|---|---|---|---|---|
| baseline | 0 | 0 | 1.000 | 安定。良作と世代交代だけでは信仰地図は変わらない |
| famine | 2 | 0 | 0.750 | 水神→稲荷（実利、飢饉直後）、山岳→浄土（救済、疫病後）。仮説1・2と整合 |
| miracle_rumor | 7 | 0 | 0.375 | 噂直後に稲荷へ3件の短期改宗（step 7-8）。step 20 の神社庇護で古典神道へ4件の揺り戻し。仮説4・5と整合 |

- 初期チューニングの教訓：信仰強度が無限成長すると慣性が鉄壁化して何も起きない。通常成長に上限（0.90）を入れ、イベント効果に全体係数（1.6）と緩い減衰（0.92）を持たせることで、危機イベントが現実的に効くようになった。

### 創発的知見（仮説リスト外）

1. **改宗の入口で定着率が分かれる**: 危機（famine）経由の早期改宗は全員定着、噂（miracle_rumor）経由は88%が離脱
2. **個人特性は変調因子**: 不安・実利欲求を上げても baseline では改宗ゼロ。改宗の駆動はイベント由来の信念間引力差
3. **寛容性は流動化装置**: tolerance +0.10 以上（famine）で習合 0→1.1、正面改宗 1.83→2.57、定着率 0.775→0.679。「寛容＝安定」ではない

## 2026-06-05（v0.5.0 母集団サンプリング、60人村 × 1,050 run）

設計（tasks/todo.md rev3、evaluator モード1 APPROVE）に基づく再実験。
再現コマンド: `experiments/run_sweep.py --sweep all --judge`（デフォルト sampled60）。
2回実行で results.tsv ×4 の byte 一致を確認済み。`--population fixed8` で v0.4.0 の
results.tsv / stats.json 全8ファイルとの byte 一致も確認済み（後方互換の証明）。

### 測定対象（estimand）の注意

- v0.4.0 の mean/std =「1つの固定村」での確率的ばらつき
- v0.5.0 の mean/std =「村の構成のばらつき + 確率的ばらつき」の混合（seed ごとに
  population.yaml のロール原型から60人を生成）
- **両バージョンの数値は直接比較できない**。下の対比表は参考対比である
- 分散の分解（村固定 × シミュレーション seed の直交設計）は次フェーズ候補

### 判定基準（実装前に宣言、rev3）

絶対下限は v0.4.0 の per-capita と**完全パリティ**（25%）: H1 = 15件（60×0.25）、
H5 早期改宗 = 15件。v0.4.0 実測の単純スケール（famine ≈ 13.5 < 15）では H1 が**通らない**
側に立つ基準であり、「通りやすい閾値を選んだ」という批判は構造的に成立しない。
注記: H5 の 15 は「早期窓内の改宗イベント数」であり、H1 の「全期間の改宗数」とは
指標が異なるが、同じ per-capita 換算を分母 60 に対して適用している（指標の性質の違いは
v0.4.0 から同様）。

### 仮説判定

| 仮説 | 判定 | 数値根拠 |
|---|---|---|
| H1 危機→救済志向 | **整合** | famine mean(conversions)=22.70 ≥ 15（パリティ下限）、> baseline mean+1σ=5.68、改宗先の99.5%が救済+実利系。**素直なスケール予想（13.5）を大きく超えた** |
| H1 補助（不安スイープ） | **整合（形式上）・実効果ほぼゼロ** | baseline 側系列 3.40 / 3.37 / 3.40 / 3.40 / 3.40（隣接減少1 ≤ 許容1で宣言基準は満たすが、**実質フラット**）。宣言した単調増加基準が平坦系列を排除できない欠陥を持っていたことをここに記録する。実質的な結論は v0.4.0 と同じ「不安は駆動因子ではなく変調因子」（famine 側も 22.43→23.00 の微増のみ、飽和率 1.7%→29.8%） |
| H2 実利圧力→現世利益 | **整合**（v0.4.0 の条件付きから昇格） | baseline 側 0.20→5.63、famine 側 10.07→31.40、**両側で単調増加**。60人村では平時でも実利欲求の効果が観測可能になった |

### v0.4.0 との参考対比（estimand が異なる点に注意）

| 指標 | 8人村 (v0.4.0) | 60人村 (v0.5.0) | per-capita |
|---|---|---|---|
| baseline 改宗 | 0.00 | 3.82 ± 1.86 | 0% → 6.4%（多様な村には自然な揺らぎがある） |
| famine 改宗 | 1.80 ± 0.40 | 22.70 ± 4.57 | 22.5% → **37.8%（規模が増幅）** |
| rumor 改宗 | 7.94 ± 0.70 | 68.46 ± 4.37 | （改宗イベント数。同一人物の再改宗を含む） |
| famine 早期改宗の定着 | 1.000 | 0.983 | 頑健 |
| rumor 早期改宗の定着 | 0.118 | 0.222 | 頑健（8割が離脱） |

### 創発的知見（v0.5.0 で新たに出たもの）

1. **規模の増幅効果**: famine の per-capita 改宗率が 22.5% → 37.8% に増えた。村が大きく
   多様になると、最初の改宗者が共同体圧力チャネルを通じて後続の改宗を呼ぶ（8人村では
   この連鎖が起きる前に候補が尽きる）
2. **対処チャネルの競合**: practical_benefit_need を上げると実利系改宗が増える一方で
   **救済系改宗が減る**（famine: salv 12.83→5.73）。救済と実利は危機対処の競合チャネル
3. **寛容性の流動化はなめらかに再現**: 8人村では閾値跨ぎが 0/8→8/8 の離散ジャンプ
   だったが、60人村では 0→56人 のなめらかな勾配（習合 0→10.5、定着率 0.64→0.51）。
   v0.4.0 の「寛容＝流動化」がアーティファクトでないことを補強
4. **噂改宗の蒸発は村構成に対して頑健**: どの村でも噂経由の早期改宗者の約8割が離脱する
