# 仮説

1. 高い不確実性と苦難は、救済志向の信念を増やす。
2. 農業・商業の圧力は、現世利益の祈願を増やす。
3. 強い共同体依存は、地域の神社や家の信仰を保存する。
4. 権威による庇護は、制度と結びついた信念を加速させる。
5. 噂は急速な伝播を生むが、定着は共同体と実利的な見返りに依存する。
6. 高い寛容性は、明確な改宗ではなく習合（シンクレティズム）を生む。

## 検証状況（2026-06-05、v0.5.0 60人村スイープ）

判定の数値根拠は `docs/experiment_log.md`、判定基準の宣言は各設計書
（v0.4.0: `docs/design_history/2026-06-05-sweeps-v0.4.md` / v0.5.0: `tasks/todo.md` rev3）を参照。
判定基準の絶対下限は両バージョンで per-capita 25% パリティ。

| # | v0.4.0（8人固定村） | v0.5.0（60人サンプリング村） | 備考 |
|---|---|---|---|
| 1 | 不整合（1.8 < 下限2） | **整合**（22.7 ≥ 下限15） | 60人村では危機改宗が per-capita でも増幅（22.5%→37.8%） |
| 2 | 条件付き整合 | **整合** | 平時でも実利欲求の効果が観測可能に（両シナリオで単調増加） |
| 3 | 判定不能 | **整合（v0.7.0）** | famine 下で保持率 0.543→0.654 単調増加（効果量 11.1pp）。雪崩加速チャネルは多数派引力に勝てず |
| 4 | 判定不能 | **整合（v0.7.0）** | 庇護後窓の古典神道改宗 25.1→48.2 単調増加。baseline 対照は全条件0件 |
| 5 | 整合 | **整合** | 噂改宗の8割蒸発は村構成に対して頑健 |
