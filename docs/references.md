## 郡モデル（v2.0）のライト調査（2026-06-07、Web検索ベース）

学術文献の精査ではなく Web 検索による概観であり、二次・三次資料を含む。
各項目の「使い方」に、モデルのどこの根拠にしたかを明記する。

### 村の規模

- 江戸時代（18–19世紀）の平均的な村: 村高400–500石・耕地約50町・**40〜50戸・人口約400人**
  - 出典: [古文書ネット「江戸時代の村のしくみ」](https://komonjyo.net/muranoshikumi.html)、
    [Wikipedia「江戸時代の日本の人口統計」](https://ja.wikipedia.org/wiki/%E6%B1%9F%E6%88%B8%E6%99%82%E4%BB%A3%E3%81%AE%E6%97%A5%E6%9C%AC%E3%81%AE%E4%BA%BA%E5%8F%A3%E7%B5%B1%E8%A8%88)
  - 使い方: **1村 = 400人**の根拠

### 身分・職業構成

- 全国の身分別人口はおよそ 農民80–85% / 武士6–7% / 町人（職人・商人）5–10%。
  武士は城下町に集住し、**村にはほぼ不在**
  - 出典: [図録・江戸時代の身分別人口](https://honkawa2.sakura.ne.jp/7860.html) ほか
  - 使い方: 村のロール構成（百姓系を約9割、職人・商人・宗教者・村役は少数）の根拠

### 宗教制度

- **寺請制度（宗門人別改）**: 寛文期以降、全戸がいずれかの寺の檀家として登録。
  同時に村の鎮守の**氏子**でもあり、信仰の併存（神仏習合）が標準状態
  - 出典: [Wikipedia「宗門人別改帳」](https://ja.wikipedia.org/wiki/%E5%AE%97%E9%96%80%E4%BA%BA%E5%88%A5%E6%94%B9%E5%B8%B3)
  - 使い方: モデルの「信仰」は所属ではなく**「主たる信心」（日々の心の重心）**と再解釈する根拠。
    「一人一信仰」を所属として読むのは史実に反する
- 江戸期の寺院は約9万カ寺（廃仏毀釈で明治初年に半減したとされる）。
  宗派規模の歴史統計は今回の調査では取得できず、現代統計（寺院数最多級=曹洞宗、
  信者数最大級=浄土真宗系）を**代理の規模感**として参照
  - 出典: [Wikipedia「日本の仏教」](https://ja.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC%E3%81%AE%E4%BB%8F%E6%95%99)、
    [宗派別寺院数ランキング](https://media.horinji.or.jp/ranking-school/)
  - 使い方: 仏教系の主たる信心は浄土系優位・禅系次点という**順序**の根拠に留める。
    具体的な確率値は**設計上の仮定**（感度分析で守る）

### 村間の交流・宗教伝播の担い手

- **御師**: 縄張りの村々を巡回して札を配り、**講**を組織し、参拝を勧誘。
  講は村を越えた宗教的・経済的ネットワーク（伊勢講・富士講・御嶽講など）
  - 出典: [武蔵御嶽神社「御師と講」](https://musashimitakejinja.jp/history/oshi-kou/)、
    [古文書ネット「講とは」](https://komonjyo.net/life/kotoha.html)
- 僧侶の旅・巡礼・行商も村と村の情報伝達の主経路
  - 出典: [村上晴澄「江戸時代の僧侶の旅と伊勢参宮」(立命館大学紀要PDF)](https://www.ritsumei.ac.jp/acd/cg/lt/rb/672/672PDF/murakami.pdf)
  - 使い方: 郡モデルの**橋渡しエージェント = 宗教者・商人**の根拠
