# Validation Plan

The first version is not a historical reconstruction. It validates whether the
simulation can produce inspectable belief diffusion dynamics.

## Checks

- Baseline keeps local belief relatively stable.
- Famine increases practical-benefit and salvation-oriented beliefs.
- Miracle rumor creates visible short-term pressure toward the target belief.
- Every conversion event must include a reason trace.
- Outputs must separate raw agent turns from aggregated metrics.
